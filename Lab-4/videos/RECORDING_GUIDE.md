# Required real gameplay recordings (record locally)

This folder intentionally does not contain fake videos. The assignment asks for genuine ~10-second recordings of the game on your computer.

## Before video — `before.mp4`
1. Open the original assigned repo at https://github.com/SETAPESU26/62_scramble and run its baseline with Python 3.10+ and `pygame` installed.
2. Record the game window for about 10 seconds.
3. Demonstrate the validation bug: note the scrambled word and test the intended answer, then show that it is rejected (or show the scrambled string accepted if reproducible).
4. Save the clip as `before.mp4` in this folder.

## After video — `after.mp4`
1. Run the updated package from its root using `python main.py`.
2. Record for about 10 seconds, showing the corrected guess behavior and at least one of: hint reveal, timer bar, or clicking letter tiles to assemble a guess. If possible, show the features in a quick sequence.
3. Save as `after.mp4` in this folder.

Windows options: Snipping Tool → Record, or Xbox Game Bar (`Win+G`). Avoid showing passwords or unrelated personal information. Verify both files play before submission.
